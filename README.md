# 🏗️ Ingeniería de Software 2

Repositorio grupal para los trabajos, talleres y proyectos desarrollados durante el semestre en la asignatura **Ingeniería de Software 2** — Fundación Universitaria Konrad Lorenz.

---

## 📌 Sobre este repositorio

Este espacio centraliza todo el trabajo del equipo a lo largo del curso: talleres, entregas parciales y proyectos. La idea es que cualquier integrante pueda entrar, ver en qué va cada entrega y aportar sin fricción, sin importar quién la haya empezado.

## 🔀 Flujo de trabajo

1. Crea una rama por tarea o entrega: `feature/nombre-taller`
2. Haz commits descriptivos: `git commit -m "feat: agrega sección X del taller Y"`
3. Sube tu rama: `git push origin feature/nombre-taller`
4. Abre un Pull Request hacia `main` para que el equipo revise antes de mergear
